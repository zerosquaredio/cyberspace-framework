# Contributing

Improvements are welcome, and so are hubs, leaves, and clients built on this
work, open or closed. If you run your own version and fix or improve
something, please send it back: everyone running the same code keeps the
network working together, and it saves you carrying your changes forward
through every update.

## How

- **Issues:** report bugs, ideas, and questions on the repo they concern.
  Not sure which? Use this one.
- **Pull requests:** small and focused is easiest to review. Say what the
  change does and why.
- **Which repo:**

  | Change | Repo |
  |---|---|
  | The framework vision, cross-project decisions | [cyberspace-framework](https://github.com/zerosquaredio/cyberspace-framework) |
  | BBS network and hub specs, hub code | [nexus-lounge](https://github.com/zerosquaredio/nexus-lounge) |
  | The ENiGMA½ AT Protocol login work | [enigma-bbs](https://github.com/zerosquaredio/enigma-bbs), branch `atproto-login`. General ENiGMA½ changes belong upstream at [NuSkooler/enigma-bbs](https://github.com/NuSkooler/enigma-bbs) |
